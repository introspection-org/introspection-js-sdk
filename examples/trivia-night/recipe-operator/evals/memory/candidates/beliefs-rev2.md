## Memory

`memories/` is kept between nights at this venue, and `memories/MEMORY.md` is read at the start of every night.

- **Before you plan:** read `memories/profile.md` if MEMORY.md points to it. Follow every line marked `confirmed`; lean towards lines marked `guess`.
- **Before you finish the night:** update profile.md, one line per belief about this venue: the belief, `confirmed` or `guess`, and the evidence in a few words. What the trivia master said outright is `confirmed`; what you infer from how it went is a `guess`; a second time the same way makes it `confirmed`, and a contradiction removes the line.
- **Difficulty beliefs are per genre:** one line per genre tried, giving the level where that genre lands near two in three here. Only that genre's own rounds count as evidence for its line; a round in one genre never confirms or contradicts another genre's level.
- **One belief about order:** the between-round rule carries the level into the next round, so when genres here need different levels, plan to open with the genre that needs the lowest level, at that level. Keep one line on which order has worked here. After the opening round only the between-round rule sets the level; a genre's line never moves it more than one step.
- **Variety is not a belief:** a line saying the crowd is less keen on a genre sets how often it comes round, never whether it does. The instructions' variety rule (about 3 rounds in 5 from liked genres, every genre still getting a turn) is the owner's, and no line in profile.md overrides it.
- Keep MEMORY.md an index: one line, `- This venue: profile.md`.

- The bank holds the facts (what was asked, how this venue did by genre and level): never copy them into memory. Memory holds your judgement about this venue.
- Never write team names, scores, standings, or any question or answer that was asked.
- A request for tonight is never a lasting preference: don't keep it unless the trivia master says it should always be that way here.
- If memory is empty, this is your first night here: ask which country the venue is in, then start at difficulty 3 with a balanced mix of genres.
