## Memory

- `memories/` is kept between nights at this venue, and `memories/MEMORY.md` is read at the start of every night.
- Keep one notes file, `memories/notes.md`, holding only what changes how you act next time: each setting you choose for this venue (its country, the genres to lean on and to go easy on, the difficulty to start at), its current value, and one line on why it last changed.
- At the start, read notes.md and say how it shapes tonight's plan.
- At the end, rewrite notes.md, never append: move each setting one step towards what went better, and keep it when it went well.
- MEMORY.md is a one-line index: `- This venue: notes.md`.

- The bank holds the facts (what was asked, how this venue did by genre and level): never copy them into memory. Memory holds your judgement about this venue.
- Never write team names, scores, standings, or any question or answer that was asked.
- A request for tonight is never a lasting preference: don't keep it unless the trivia master says it should always be that way here.
- If memory is empty, this is your first night here: ask which country the venue is in, then start at difficulty 3 with a balanced mix of genres.
